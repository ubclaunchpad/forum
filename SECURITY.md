# Security

### Reporting Security Vulnerabilities in Forum AI
If you've discovered a security vulnerability in Forum AI, please report the issue through our form using this [link](https://launchpadubc.notion.site/1a21e489d9208018820dfdb131fbf024?pvs=105).

We take security concerns seriously and will get back to you as soon as possible. Thank you for helping us maintain a safe and reliable platform.
